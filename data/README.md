# Dataset

`leads.csv` is a deterministic synthetic B2B lead-conversion dataset generated by:

```bash
python -m ml.generate_data --rows 5000 --seed 42
```

The dataset exists for architecture and ML lifecycle learning. It is not historical CRM data
and its metrics must not be presented as real business performance.

See `DATA_CARD.md` for the feature contract, synthetic assumptions, target definition,
limitations, and known sources of bias.
